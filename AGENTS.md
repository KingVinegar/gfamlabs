## School-owned Mac protocol — all GFAM Labs projects

When this repository is checked out on a school-owned Mac, it is an approved development workspace for GFAM Labs projects only, subject to the school's applicable device and acceptable-use policies. It is not a general-purpose agent environment.

- A local task must be assigned to one GFAM project directory at a time. It may read the root policy and the project's directly relevant documentation, but it must not inspect, index, stage, or alter unrelated project directories unless the owner explicitly expands that task's scope.
- Do not inspect, search, index, upload, modify, or summarize data outside this repository: school files, personal files, system files, browser data, cloud-storage data, mail, calendar, contacts, photos, notes, messages, or other app data are out of scope.
- Do not use symlinks, parent traversal, broad filesystem scans, or tooling that could widen the workspace boundary.
- Do not install software, packages, extensions, background services, VPNs, developer dependencies, or system configuration without explicit owner approval and confirmation that school policy permits it.
- Network access is deny-by-default. Before a task uses it, the owner must approve the exact destination and purpose. Git synchronization is permitted only through an owner-selected GFAM repository and only for the assigned project's files.
- Do not create accounts, transmit credentials, use API keys, access App Store Connect, sign builds, enable analytics, submit builds, publish, or contact third parties unless separately authorized by the owner at the point of action.
- Prefer Simulator-only local work until the owner explicitly authorizes Apple-device signing or external distribution. Keep screenshots, generated assets, and build artifacts within the assigned project directory.
- Each local project agent must provide a compact handoff: changed files, checks performed, separate functional and experiential status, evidence limitations, and any needed owner decision or permission.
